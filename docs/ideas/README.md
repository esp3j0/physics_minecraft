# 设想池(ideas)

存放**还没到立项程度的想法**:玩法设想、架构猜想、"以后可能要做"的方向。

- **不是需求,不承诺实现**。需求的单一事实来源仍是 `docs/requirements/`;
- 设想可以粗糙、可以有漏洞;记录时尽量附上已经梳理出的问题和前置依赖;
- 设想成熟后**转成 REQ**:新建 REQ 文档,在设想文件头部标注"已转 REQ-XXX";
- 设想中的某一点被某个 REQ 吸收时,在该点旁标注"已并入 REQ-XXX",设想文件本身保留;
- 较大的设计讨论也可能放在 GitHub issue(标签 `design`),这里只做索引。

## 命名

`IDEA-<三位编号>-<短名>.md`。文件头写:状态(设想 / 部分并入 / 已转 REQ / 放弃)、提出日期、来源。
