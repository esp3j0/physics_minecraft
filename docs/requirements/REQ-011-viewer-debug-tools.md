## 1. 背景与目标

REQ-009 / REQ-010 加入了地形破坏、粘结塌落、撞击冲量流断开、复合体摔断与撞散。目前交互 viewer 只有 **B**(原地掉一个零速单格
方块)和 **X**(引爆),最近两个修订的能力(方块撞墙按冲量流断开、条状刚体落地摔断或被撞散、击退)手动几乎触发不了,只能靠
冒烟场景回放观看。用户需要亲手试、亲眼看,给物理调参提供反馈。

本需求给**交互模式**的 viewer 加一套调试工具:

1. **发射**:沿准星方向以可调速度打出单格或复合体方块;
2. **放置 / 拆除与预制结构**:准星处放、拆单个方块;一键搭常用测试结构;
3. **调试面板**:实体数、破坏与冲量流计数、最近冲量流事件的 `s` / `C`(离断开还差多少);
4. **场景布景**:载入一个冒烟场景的搭建部分,之后由用户手动玩;可重建、可播放场景原本的动作。

定位:**开发者工具**,不是玩法。正式客户端(#9)以后另立需求;本需求的输入→命令层、拾取与预制结构的纯函数可被复用。

## 2. 总体约束

- **脚本模式不变**:`viewer --script` 的行为、截图、manifest 逐位不变;本需求的按键、面板、遥测订阅只在交互模式生效。
  全量冒烟必须照旧通过(AC-W12)。
- **模拟不变**:遥测只读,不入快照、不参与 canonical 输入排序、不改任何模拟分支;订阅与否不改变任何一拍的模拟结果(AC-W9)。
- **协议只追加**(REQ-003):新增一个 C2S 变体、一个 S2C 变体,不改既有变体。未订阅的客户端收到的帧序列与现在逐位相同。
- **服务器命令全部走现有白名单**:发射 = `C2S::Spawn`(带速度、形状),放置 / 拆除 / 预制结构 / 布景 = `SetBlock`
  (预制结构与布景的 fill 按现有"同帧命令批"发出,REQ-010 终审返修 1),不新增服务器命令。
- **逻辑与渲染分离**:拾取、预制结构展开、发射参数、布景切分、面板文本全部写成纯函数,放在 `crates/viewer/src/tools/`,
  单元测试覆盖;`render.rs` 只做按键到纯函数的接线(REQ-004A"渲染代码不写窗口类测试"的决议继续有效)。

## 3. 需求内容

### 3.1 当前工具状态与按键

交互模式维护一份工具状态:**当前材料**、**当前发射形状**、**发射速度**、**当前预制结构**。现有按键(WASD、鼠标、Shift / Ctrl、
空格、M、B、X)行为不变。新增按键(D1):

| 按键 | 作用 |
| --- | --- |
| `1` / `2` / `3` / `4` | 当前材料 = 土 / 石 / 沙 / 基岩 |
| 鼠标左键 | 拆除准星指向的方块(§3.3) |
| 鼠标右键 | 在准星指向的面外侧放一格当前材料(§3.3) |
| `F` | 发射(§3.2) |
| `E` | 切换发射形状(循环) |
| 鼠标滚轮 | 发射速度 ±5 m/s |
| `T` | 切换预制结构(循环) |
| `G` | 在准星处放置当前预制结构(§3.4) |
| `F3` | 显示 / 隐藏调试面板(§3.5;默认显示) |
| `C` | 调试面板计数清零(只清客户端基线,§3.5) |
| `R` | 重建布景(仅 `--stage` 时,§3.6) |
| `K` | 播放场景动作(仅 `--stage` 时,§3.6) |
| `H` | 显示 / 隐藏按键帮助 |

鼠标释放(M)时左右键、滚轮不触发工具(避免点 HUD 时误拆)。

### 3.2 发射

- **形状**(`E` 循环;D2):

  | 序 | 名称 | 格(局部 u = 右、v = 上、w = 前) | 用途 |
  | --- | --- | --- | --- |
  | 1 | 单格 | (0,0,0) | 撞墙、撞刚体 |
  | 2 | 6 格条·纵 | w = 0..5 | 轴向撞击(punch 场景) |
  | 3 | 6 格条·横 | u = 0..5 | 侧向撞击、被撞物的击退 |
  | 4 | 2×2 板 | u = 0..1、v = 0..1 | 面撞击 |
  | 5 | 3×3×3 块 | u, v, w = 0..2 | 重物破墙 |

  局部轴 → 世界轴:`w` = 相机水平朝向取整到最近的 ±x / ±z,`u` = `w` 绕 y 右转 90°,`v` = +y;形状偏移按世界轴写入
  `CompoundShape`,刚体旋转为单位四元数(不随俯仰倾斜)。
- **材料**:当前材料;基岩不可发射(面板提示,不发命令)。
- **出生位置**:形状原点格(偏移 [0,0,0])的格心 = 相机位置 + 视线方向 × `d`,`d` = 2 m + 形状沿视线方向的最大延伸;
  出生时任何一格的格心落在实心方块里(按客户端已收到的地形判定)→ 拒绝发射并提示。
- **速度**:`linvel` = 视线方向(含俯仰)× 发射速度;速度范围 **5–55 m/s**,默认 20 m/s,步长 5。上限取自 REQ-010 §5.8.5:
  生产代码不开 CCD,约 60 m/s 起单格一拍越过一格,事件变形。
- **组装**:单格发 `EntityDesc { block = 当前材料, shape = None, 半边长同 B 键 }`;复合体复用脚本引擎 `spawn.shape` 的组装路径
  (`EntityDesc::compound(COMPOUND_HALF_SIZE, shape)`,每格同一材料),与冒烟场景发出的完全同型。
- 出生在未装载 chunk 时服务器照现有规则拒绝,viewer 不另做判断。

### 3.3 拾取、放置与拆除

- **拾取**:从相机沿视线做体素 DDA 遍历(客户端已收到的 chunk 数据),最远 48 m,命中第一个非空气格为**目标格**,
  进入目标格时穿过的那个面为**命中面**;未装载区域视为空气继续前进;无命中 = 无目标。
- 目标格画线框高亮(颜色区分基岩);面板显示目标格坐标与方块名。
- **拆除**(左键):对目标格发 `SetBlock { pos, AIR }`。
- **放置**(右键):对命中面外侧相邻格发 `SetBlock { pos, 当前材料 }`;该格不是空气(不会发生,防御)或在世界 y 范围外时不发。
- 不检查放置格里是否有活实体(服务器现有规则处理)。

### 3.4 预制结构

- `G` 放置:锚点 = 命中面外侧相邻格(通常是地面上方一格);朝向 = 相机水平朝向取整(同 §3.2 的 u / w),结构"正对相机"。
- 每个结构展开后格数 ≤ 64(= `FILL_BATCH_PER_FRAME`),作为**一个同帧命令批**发出,保证同一拍落地(避免承载判定看到半个结构)。
- 结构表(局部坐标,锚点 = (0,0,0),u 向右、v 向上、w 向前;D3):

  | 序 | 名称 | 组成 | 格数 | 试什么 |
  | --- | --- | --- | --- | --- |
  | 1 | 土墙 | 土:u = −3..3、v = 0..4、w = 3;基岩:u = −3..3、v = −1、w = 3(替换地面一行作墙脚) | 42 | 发射物撞墙(§5.7) |
  | 2 | 石柱 | 石:u = 0、v = 0..3、w = 3 | 4 | 侧撞柱身从柱脚断开(石-土界面) |
  | 3 | 石桥 | 石柱:u = −3 与 u = 3,v = 0..2,w = 3;桥面石:u = −4..4、v = 3、w = 3 | 15 | 拆一根柱 → 桥面整块下落 / 摔断 |
  | 4 | 土门楣门框 | 石柱:u = −3 与 u = 3,v = 0..2,w = 3;土门楣:u = −3..3、v = 3、w = 3 | 13 | 拆柱 → 门楣塌落;粘性差异 |
  | 5 | 石 7 字悬臂 | 石:u = 0、v = 0..3、w = 3;石:u = 1..4、v = 3、w = 3 | 8 | 撞拐角 → 整体断下倾倒 |

  w = 3:结构离锚点 3 格远,放下后正好在准星前方,相机不在结构里。
- 结构的任何一格在世界 y 范围外 → 整个结构不发,提示。已有方块直接覆盖(SetBlock 语义)。

### 3.5 调试面板

#### 3.5.1 服务端事件摘要(只读遥测)

- **事件摘要类型**(`physics-sim`,`Copy`):`FlowEventInfo { kind, supply, cut, broke, detached_cells, position }`
  - `kind`:`Impact`(§5.7 撞击冲量流,撞地形)/ `Compound`(§5.8 复合体冲量流);
  - `supply` / `cut`:该事件的 `s` 与最小割 `C`(N·s;由量化值 `supply_q` / `cut_q` 换算,与判定同一份数据);
  - `broke` = `C < s`;`detached_cells` = 断下格数 |S|(未断为 0);
  - `position`:世界坐标——`Impact` 取被撞格格心,`Compound` 取该刚体本拍步进后的平移。
- **只记建网求值的事件**:预筛跳过的不记(无 `C`)。§7 旧路径(`compound_flow = false`)不记。
- **每分片每拍至多一条**:`Outbox` 追加 `flow_event: Option<FlowEventInfo>`,取本拍"最危险"的一条——`s / C` 最大者
  (`C = 0` 视为无穷大);并列按 `kind`(Impact 先)、`position` 各分量的位模式升序决出,保证确定。
- 调度器合计:`TickSummary` 追加 `flow_event: Option<FlowEventInfo>`,全部分片按同一规则取一条(`TickSummary` 保持 `Copy`)。
- 纯计数、每拍重算、不入快照、不进命令日志;不改任何判定分支。

#### 3.5.2 协议与下发

- `C2S::SubscribeDebug`(追加变体,无字段):该连接开始接收调试遥测;重复发送幂等;断连即失效。
- `S2C::DebugStats { tick, counters: DebugCounters, recent: Vec<(Tick, FlowEventInfo 的协议镜像)> }`(追加变体):
  - `DebugCounters`(sim-api 内定义的协议结构,不直接暴露 physics-sim 类型):服务器启动以来的**累计值**——
    `impact_flow_events`、`impact_flow_breaks`、`impact_flow_detached_cells`、`compound_flow_events`、`compound_flow_breaks`、
    `compound_flow_detached_cells`、`compound_flow_corrections`、`bonds_broken`、`compounds_spawned`、`compounds_solidified`、
    `cells_blasted`、`cells_impacted`、`cells_collapsed`;
  - `recent`:驱动保留最近 8 条非空 `flow_event`(带拍号,旧→新);
  - 驱动对已订阅连接每 10 拍(20 Hz 下 2 Hz)发一次;无订阅者时不组装。
- 未订阅的连接帧序列与现在逐位相同;脚本模式不订阅。

#### 3.5.3 面板内容(viewer)

`F3` 切换,交互模式默认显示,位于现有四行 HUD 下方。内容:

1. **工具**:材料、发射形状、速度、预制结构;拾取目标格坐标与方块名(无目标显示"—");
2. **实体**:本地活实体数,其中复合体数(有形状的实体);
3. **计数**:`DebugCounters` 各项相对**基线**的增量,`C` 键把当前值设为基线(首次收到时自动设基线);未订阅成功前显示"等待服务器";
4. **最近事件**(最新 5 条,新的在上):`t=拍号 类型 s=… C=… C/s=… 断|扛 |S|=… @(x,y,z)`,数值 1 位小数,坐标取整;
   `C/s < 1` 即断,用醒目颜色。
5. 提示行:操作被拒绝的原因(基岩不可发射、出生位置在方块里、结构越界、无目标),显示 3 秒。

### 3.6 场景布景

- **入口**:`viewer --stage <场景文件>`(交互模式;与 `--script` 互斥,`--out` 不适用)。
- **切分**:场景步骤按顺序分成两段——**布景段** = 第一个"动作步骤"之前的全部步骤,**动作段** = 其余步骤。动作步骤 =
  `spawn`、`detonate`,或写入空气的 `set_block` / `fill`(拆支撑、拆脚手架)。按现有场景核对:punch、pillar、bridge-collapse 的
  布景是结构本身;door-lintel、cantilever 的布景含临时脚手架,动作从拆脚手架开始;beam-whole、sand-column 的动作从拆柱 / 拆石块开始;
  impact-corner 的布景是完整门框,动作 = 拆左柱成 7 字 + 发射;compound-snap、shatter、crater 的布景只有相机;materials 全部是布景。
- **布景段执行**:连接并装载后自动执行一次。只执行 `camera`、`look_at`、`set_block`、`fill`、`wait_ticks`、`wait_until`;
  其余动作(`screenshot`、`check`、`fly`、`couple` 等)跳过。`fill` 照脚本引擎的分批规则发出。`wait_until` 超时不退出,
  面板提示"布景等待超时:<条件>"后继续下一步。
- **`R` 重建**:先对当前所有活实体发 `RemoveEntity`,再重新执行布景段(相机回到布景位姿)。散落在别处的方块不清理(非目标)。
- **`K` 播放动作段**:执行动作段里的 `spawn`、`detonate`、`set_block`、`fill`、`wait_ticks`、`wait_until`;跳过 `screenshot`、`check`、
  相机类步骤(相机留给用户)。播放中再按 `K` 无效;播放完提示"动作播放完毕"。
- **`[server]` 覆盖不生效**:服务器已在运行。场景含 `[server]` 表时面板提示"本场景的 [server] 设置未应用,需要时用
  `cargo xtask smoke`"。破坏、粘结、冲量流在服务器默认配置里都是开启的,现有 REQ-009 / REQ-010 场景大多不受影响。
- 复用 `script::parse` 解析场景;引擎复用或在 `tools/stage.rs` 里另写一个只支持上述动作的小执行器,二者择一,由实施方定,
  但**不得改变脚本模式的行为**。

## 4. 验收标准

纯函数部分逐条落成 `crates/viewer` 单元测试;协议与遥测落成 `crates/e2e` / `crates/app` / `crates/shard` 测试。

- **AC-W1 拾取**:DDA 在构造的小世界里——轴对齐、斜向、穿过 chunk 边界、贴棱、48 m 外无命中、起点在实心格内——
  目标格与命中面均正确;命中面外侧格 = 目标格 + 面法向。
- **AC-W2 轴取整**:相机水平朝向在八个象限边界两侧各取一点,`w` 取整到正确的 ±x / ±z,`u = w` 右转 90°;正上 / 正下看时取整稳定
  (按 yaw 取,不受俯仰影响)。
- **AC-W3 发射参数**:五种形状 × 四个朝向,`CompoundShape` 偏移、出生位置(`d` 的取值)、`linvel` 与表一致;基岩、出生格在实心方块里
  两种情况返回拒绝原因;速度夹在 5–55。
- **AC-W4 发射同型**:同一形状经发射路径与经脚本 `spawn.shape` 路径组装出的 `EntityDesc` 相等。
- **AC-W5 预制结构**:五个结构 × 四个朝向,展开格集合与 §3.4 表一致(含基岩墙脚);格数 ≤ 64;越界整构拒绝;
  展开结果作为单个 `command_batch` 发出(对控制句柄打桩断言只有一条 `Batch`)。
- **AC-W6 事件摘要**:`physics-sim` 测试——单格撞土墙(§5.7)、6 格土条端角落地(§5.8)各产生 `flow_event`,`supply` / `cut` 与该事件的
  判定量一致(与 `impact_flow` / `compound_flow` 现有测试的量逐值对上),`broke` 与实际是否断开一致;预筛命中不产生;
  一拍两事件取 `s / C` 大者;`compound_flow = false` 时为 `None`。
- **AC-W7 合计**:`shard` 测试——两分片同拍各一条,`TickSummary::flow_event` 按 §3.5.1 规则取一条,并列规则确定。
- **AC-W8 协议**:`C2S::SubscribeDebug` / `S2C::DebugStats` 编解码往返;既有变体的判别值与编码不变(追加在末尾)。
- **AC-W9 模拟不变**:同一组命令,遥测订阅开 / 关两次运行,每拍全部实体状态(四向量 `==`)与方块变更逐位相同
  (照 `consistency.rs` 现有逐位对照的做法);未订阅连接收到的帧序列与改动前同构
  (现有 e2e 网络测试不改断言全部通过)。
- **AC-W10 下发**:e2e——订阅后每 10 拍收到一次 `DebugStats`,累计值单调不减;制造一次撞击断开后 `impact_flow_breaks` 增加、
  `recent` 末条为该事件;未订阅的第二个连接收不到 `DebugStats`。
- **AC-W11 面板文本**:面板文本生成函数——基线差、`C` 清零、`C/s` 与断 / 扛标注、最近 5 条倒序、未订阅提示、拒绝提示 3 秒过期。
- **AC-W12 脚本模式不变**:`--script` 路径不订阅遥测、不响应新按键;全量 `cargo xtask smoke` 通过(带 AI 审图)。
- **AC-W13 布景切分与执行**:用现有场景文件(`req010-impact-punch`、`req010-door-lintel`、`req010-beam-whole`、`req010-impact-corner`、
  `req010-shatter`、`req009-materials`)断言布景段 / 动作段的切分点与 §3.6 的核对结果一致;
  布景执行器对打桩世界发出的命令序列 = 布景段中 `set_block` / `fill` 的展开(分批规则同脚本引擎);`R` 先发 `RemoveEntity`
  (每个活实体一条)再重放布景;`K` 只发动作段的 `spawn` / `detonate` / 方块命令;`--stage` 与 `--script` 互斥(CLI 解析测试)。
- **AC-W14 人工验收**(用户,§5):按 §5 清单逐项操作,每项现象符合描述。

## 5. 人工验收清单(用户执行,AC-W14)

服务器 `cargo run --release -p app`,viewer `cargo run --release -p viewer`:

1. 帮助:按 `H` 出现按键表,再按消失。
2. 拾取:准星扫过地面,线框跟随;面板显示目标坐标与"dirt"。
3. 拆除 / 放置:左键拆一格,地面出现坑;按 `2` 后右键,坑上方出现石块。
4. 预制结构:`T` 选"土墙",`G` 放下,准星前方 3 格出现 7×5 土墙;面板事件区无变化。
5. 发射撞墙:单格石、30 m/s,`F` 打墙中部 → 墙出现缺口,碎土飞到墙后;面板最近事件出现 `Impact … 断`,`C/s < 1`。
6. 复合体:`E` 选"6 格条·横"、土、20 m/s,对空中斜向上发射,落地 → 观察是否摔断;面板出现 `Compound` 事件,`C/s` 与断 / 扛一致。
7. 塌落:`T` 选"石桥",`G` 放下,左键拆掉一根石柱 → 桥面整块下落;计数 `compounds_spawned` 增加。
8. 计数清零:按 `C`,计数归零;再打一次墙,增量重新累计。
9. 布景:`cargo run --release -p viewer -- --stage smoke/scenarios/req010-impact-punch.toml` → 自动搭好墙、相机就位;`K` 播放 →
   石条撞墙;`R` → 实体清除、墙重建;之后可用 `F` 自己打。
10. 速度上限:滚轮加到上限,面板显示 55 m/s 不再增加。
