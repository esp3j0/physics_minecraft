## 说明

- **一个 REQ 一个 issue**:需求、任务书、AC、提交记录都挂在 issue;仓库文档是
  单一事实来源。
- **历史提交补录**:2026-10-18 之前的提交已在对应 issue 正文里补录 commit 链接;
  不改写历史、不 rebase。
- **新提交**:commit message 末尾加 `Refs #<issue>`;PR 用 `Closes #<issue>`。
- **完成**:REQ 文档状态改“已完成” → 关闭 issue(completed)→ 更新本表。
