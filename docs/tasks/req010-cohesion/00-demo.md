## 目的

REQ-010 的数值全是占位(各材料承载粘结 B、切块边长 S、各种上限),承载判定的代价、复合体落定后能否整块吸附、
用 REQ-009 的撞击阈值 I 当撞击粘结是否合理,都没有实测。本 demo 用最低成本回答这些问题,并找出需求本身的漏洞。

## 环境与约定

- 解释器 `.venv\Scripts\python.exe`,已装 `rapier3d==0.36.0` 与 `numpy`;**不要 pip install 任何东西**(没有 matplotlib,
  图用 ASCII 输出);绑定用法以 [`demos/_API_NOTES.md`](../../../demos/_API_NOTES.md) 为准;
  可以导入或复制 `demos/terrain-destruction/common.py` 里的工具(薄片地形、静止判据等);
- 只新建 `demos/cohesion/` 下的文件;新实测到的绑定用法追加到 `_API_NOTES.md`;不改 `docs/`、不改 `crates/`;
- 坐标约定同 REQ-009 demo:局部坐标,地表在 y = 0;超平坦地面 = y −4 为 bedrock、y −3…−1 为 dirt;格 (x,y,z) 覆盖
  [x,x+1)³;地形碰撞体按生产口径用暴露面薄片(半厚 0.075);
- 材料:stone(B 占位 8,I 18)、dirt(B 3,I 7)、sand(B 0,I 4)、bedrock(B ∞,I ∞);格重 1(整数);
  复合体每格 cuboid 半边长 0.45、密度 1(每格 0.729 kg)、摩擦 0.6、弹性 0.1;dt = 1/60;
- 每个脚本单独可运行,10 分钟内跑完,打印结果表;README 记录运行方式、全部结果表、结论与推荐值。

### 接触冲量怎么读

`_API_NOTES.md` 记录了一个绑定缺陷:**复合 collider 参与的接触对,`point.impulse` 恒为 0**。碎裂需要"复合体每一格各受了
多少冲量",按下面的顺序找可行路,并把结论写进 README 与 `_API_NOTES.md`:

1. 复合体做成**一个刚体挂多个 primitive cuboid collider**(每格一个,不用 `Collider.compound`),地形也做成固定体上的
   **多个 primitive 薄片 collider**(不用复合体),看 primitive↔primitive 的接触点冲量能否读到、是否与动量差分吻合;
2. 不行就在 `demos/cohesion/spike/` 建一个独立的 Rust 小工程(`Cargo.toml` 写 `rapier3d = "=0.36.1"` 并带空的
   `[workspace]` 表,不加入主 workspace;构建用 `cargo run --release --target-dir target/cohesion-spike`,构建产物不提交),
   用 Rust 直接读接触点冲量(REQ-009 的撞击 spike 已证实 Rust 侧可读复合体接触点冲量)。

## 脚本与要测的东西

### 1. `load.py`(纯体素,承载判定)

按 REQ-010 §4 实现:接地格(按柱缓存)、悬挑区(从触发格出发,只走非接地实心格,上限 `load_max_cells`)、
整数容量网络(源点 → 悬挑格 1;向下 ∞;水平与向上 `min(B_a, B_b)`,为 0 即无边;接地格为汇;未装载 chunk 的相邻格 ∞ 连汇)、
最大流、F = 残量网络中源点可达的悬挑格。**用两种最大流算法**(例如 Edmonds–Karp 与 Dinic,或推送-重贴标签)各算一遍,
逐结构核对 F 完全相同。

结构(每个都打印 F 的大小、被切断的粘结数、悬挑区访问格数、耗时;代表性结构打印 x–y 剖面 ASCII 图,标出 F):

1. **门框**:两根 5 高石柱,门楣 7 格宽(两端各压在柱顶),门楣分别为 dirt 与 stone;移走左柱(整根);
2. **单柱桥**:一根石柱撑一条石桥面,柱在桥面一端与正中两种;桥面长度扫描 4…20;
3. **悬臂**:从石墙伸出的悬臂,长度扫描 1…20,厚 1 与厚 2,材料 dirt / stone;
4. **悬臂加重**(D8):8 格石悬臂末端上方再放 1、2、4 格石头;
5. **拱**:跨度 9 的半圆石拱,分别移走拱顶、移走一条拱腿;
6. **T 形**:一根石柱顶上一条左右对称的横梁,两侧各长 3…10;
7. **塔**:1×1×20 石塔切断底部一格;
8. **平台**:4 根柱子撑起的 20×20 石平台,逐根移走柱子;
9. **沙子**:贴在墙侧的沙、立在被移走格上的沙柱、压在石悬臂上的沙;与 REQ-009 的沙子规则逐格对照;
10. **弹坑地面**:超平坦地面上用 REQ-009 推荐配置(`power 12, radius 8`,射线衰减,见 `demos/terrain-destruction/crater.py`)
    炸出的坑,以破坏格为触发集——应全部接地、F 为空,记录访问格数(这是最常见的情况,代价必须接近零);
11. **大薄板**:30×30 的 1 格厚石板只在四边有支撑(悬挑区约 900 格),测最坏情况耗时;另做一个超过 `load_max_cells` 的例子,
    确认按稳定处理;
12. **退化对照**:把 stone 与 dirt 的 B 设为 ∞,F 必须与 REQ-009 的连通性结论(`demos/terrain-destruction/collapse.py`
    的全量连通分量真值)完全一致;
13. **触发顺序无关**:同一结构随机打乱触发格顺序 20 次,F 不变。

**B 扫描**:stone ∈ {4, 6, 8, 12, 16},dirt ∈ {1, 2, 3, 4};对照下面的设计意图给出推荐值。

**切块**(D3):对每个非空 F,先按粘结连通(B > 0)分组,再用世界对齐、边长 S ∈ {4, 6, 7} 的立方网格切段,
打印各段格数、包络半径 ρ(原点 = 包围盒中心取整到最近的格中心;ρ = max 格中心到原点距离 + 0.45·√3)。

**跨分片**:把世界在 x = 0 处切成两个分片,各自只用自己的视图(本体区 + 16 m 扩张区;更远处视为未装载)求 F、
只转换本体区内的格,另一边的写入晚一拍才看见;逐拍模拟门框、单柱桥、平台三个结构骑在 x = 0 上的情形,核对:
各拍转换的并集与单世界 F 相同、没有格被转换两次;若出现"多塌"或"少塌",列出例子并分析根因。

### 2. `compound.py`(rapier,复合体落定)

- 复合体:6 格石梁(1×1×6)、L 形(4+3 格)、2×2×2 立方、3×1×3 板;
- 落法:平落(各高 1、2、5、10 m)、竖落(长轴竖直)、初始倾斜 20° 与 45°、落在地面上散放的 3 个单格方块上(会被垫斜);
- 每次记录:满足凝固判据(线速度 < 0.1 m/s 且角速度 < 0.05 rad/s 连续 20 拍,且最近 20 拍位移 ≤ 3 mm)所需拍数;
  按 REQ-010 §8.1 吸附后的 snap 误差(所有格的最大位移、角度误差);是否在 `max_snap_blocks = 0.5`、`max_snap_angle_deg = 45`
  之内(即能否整块凝固);吸附目标格是否与地形或其他方块重叠;
- **生成时的初始重叠**:在一个"断面"旁零速度生成复合体——6 格梁的一端紧贴一面石墙(与墙的薄片重叠 0.025),
  记录前 10 拍的最大速度、是否被墙面摩擦卡住(下落是否明显慢于自由落体);
- **碰撞体做法对比**:每格一个 cuboid 与"合并成最少的长方体"两种,落定拍数与结果是否一致、单步耗时;
- 汇总:多大比例的情况能整块凝固;倾斜搁置(需按 D5 散成单格)的常见原因。

### 3. `fracture.py`(rapier 或 Rust spike,碎裂冲量)

- 按"接触冲量怎么读"找到可行路后,测复合体**每一格**的接触冲量(只计接近速度 ≥ 1 m/s 的接触点,同一格的点相加);
- 场景:6 格梁平落(1、2、4、8、16、32 m)、角先着地(倾斜 30°,同样高度)、竖落;2×2×2 立方平落;1×1×6 石塔从直立状态
  倾倒砸地;复合体静置地面 300 拍;梁两端搭在两个方块上、中间悬空静置 300 拍;
- 每个场景:各格峰值冲量表;按 REQ-010 §7.1(`J_c ≥ min(I_c, I_n)` 断开这根粘结)离线判定会断哪些粘结、碎成几段;
  stone 与 dirt 两种材料各给一遍;
- 结论:静置是否从不断键;"从多高摔碎"是否合理;如果复用 I 不合理,给出替代建议(例如单独的撞击粘结值)及根因。

### 4. `bridge.py`(rapier,石桥整块塌落)

- 20 格石桥(1×1×20)离地 6 m,同时失去全部支撑,三种做法对比:REQ-009 逐格(20 个单格)、按 S = 6 切段(视位置 3–4 段)、
  不切(一个 20 格复合体,仅作参照);
- 输出:全部静止所需拍数、醒着的刚体数与碰撞体数、落地后的分布(ASCII 俯视图)、各段能否整块凝固、
  落定后地面上的格是否连成一排;
- 评价切段后的塌落形态是否可接受。

## 设计意图(请对照给出推荐值)

- 石柱 + 7 格土门楣,移走一根柱子 → 门楣悬空部分断下;石门楣 → 挂得住;
- 石悬臂 6 格挂得住、12 格断下;土悬臂 1–2 格挂得住(自然地形的小悬崖不该一碰就塌);
- 弹坑地面的承载判定访问格数接近零;
- 石桥面从约 5 m 高平落不碎;土桥面从同样高度平落碎成几段;静置的复合体永不断键;
- 6 格石梁平落后多数情况能整块凝固。
