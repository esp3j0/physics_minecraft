# solidify-bridge:体素层 ↔ 实体层"凝固桥"可行性验证

## 对应的架构问题

体素↔实体混合架构的既定共识"凝固桥":动态刚体停止运动后,按
**读位姿 → snap 去旋转 → snap 位置 → 写体素数组 → 换静态 collider → 删刚体**
迁移到体素层。本 demo 验证:该流程是否可行、snap 误差多大、桥本身耗时多少,
并对比两种(实做三种)触发策略。

## 场景与约定

- 地面:FIXED `cuboid(50, 0.5, 50)` @ (0, -0.5, 0),顶面 y=0;重力 (0, -9.81, 0),dt=1/60。
- 立方体:1×1×1 动态,从 (0, 10, 0) 落下,初线速度 (0.5, 0, 0)、初角速度 (2, 1, 0.5),
  落地翻滚直至静止。
- **体素约定:格点在整数坐标**,格 (i,j,k) 覆盖 [i,i+1)³,**体素中心 = (i+0.5, j+0.5, k+0.5)**。
  snap 位置 = 质心每维取 `cell = floor(c)`、吸附到 `cell+0.5`;地面顶面 y=0 时第一层
  体素中心恰为 y=0.5,块底与地面零穿深、层间自然无缝堆叠(叠放时 floor(1.4999)=1 同理自洽)。
- snap 旋转:用 numpy 枚举 24 个轴对齐朝向(符号置换矩阵,det=+1,即立方体旋转群),
  取与当前姿态转角最小者(`arccos((trace(R^T·C)-1)/2)`);写回时矩阵→缩放轴角向量。
- 桥操作单独计时:remove 动态体 → 同位置 add FIXED 体 + `Collider.cuboid(0.5,0.5,0.5)`
  → 格号写入 `set`(体素数组的占位表示)。
- 验证:凝固后从块顶上方 5 格(球底距块顶 5 格)掉 r=0.5 的球,跑 600 tick,
  检查球稳定停在块上(末 100 tick 均速 <0.05)、无穿模(球底 ≥ 块顶 − 0.01 m,
  取末 100 tick 平均)、全程位置有限。

## 相对任务书的改动(仅一处,其余按原设计)

- 追加第三组对照 **P2-宽松**(lin<0.3、ang<0.5、连续 10 tick):P2-标准(0.1/0.05×20)
  在本场景与 P1 误差完全相同,无法展示权衡曲线,故加一组更宽阈值作对照。
- 验证球带 0.05 m/s 微水平速度 + 角阻尼 2.0:本绑定未暴露滚动摩擦,球在平面上
  一旦纯滚动永不减速,用角阻尼近似"滚一段后停下"。

## 结论

1. **凝固桥可行、便宜、干净。** 单块桥操作 0.02~0.07 ms(≈16.7 ms 帧预算的
   0.1%~0.4%),snap 后块与地面零穿深,后续 600 tick 上滚球稳定停在块顶
   (陷入 0.16 mm,远小于 10 mm 容差),无 NaN/爆炸。
2. **snap 误差由"物理体停在哪"决定,与触发策略几乎无关。** 本例立方体平躺
   但 yaw 停在 27.39°、质心停在两格之间,snap 修正 383 mm(水平)+ 27.4°;
   三种策略误差逐位相同——因为平地+摩擦下刚体是"硬停"(从 >0.3 m/s 直接
   掉到 ≈0,没有慢爬行期),各组触发时体都已实际静止。
3. **P2 触发只比 P1 早 12 tick,宽松 P2 早 26 tick,均无精度代价;P1 的
   "睡眠保证对齐"是错觉。** rapier 默认睡眠角阈值 0.5 rad/s 很松,本例体睡眠时
   yaw 偏了 27.4°——**无论何种触发,snap 去旋转都是必须的**,不能省。
4. 推荐:**P2 速度阈值(lin<0.1、ang<0.05、连续 20 tick)+ 睡眠兜底**
   (等满 1~2 s 未触发则强制走 P1 路径);P2-宽松可再省 0.2 s 但抗噪余量小。

## 对架构文档的建议

1. **桥接口按"批量、异步"设计**:单次桥成本可忽略(≪1% 帧预算),真正的成本在
   触发延迟(3.6~4.0 s 才能凝固);建议每帧收集所有满足 P2 条件的刚体,一次循环
   批量 remove/add(摊销到一次物理管线往返),而不是逐体触发。
2. **触发条件写入接口契约**:默认 lin<0.1 且 ang<0.05 连续 20 tick;同时保留
   "距理想体素中心 > 半格 或 角误差 > 45° 时改等睡眠"的升级路径——平地硬停
   场景两者等价,但斜坡/堆叠慢爬行场景 P2 的 snap 误差会显著大于 P1(本实验未
   覆盖,建议补一组斜坡 demo 再定稿)。
3. **体素约定与实现要点固化**:格点取整、中心 = 格 + 0.5、`cell = floor(质心)`
   使凝固块与地面/层间零穿深且天然可堆叠;snap 后 FIXED 体朝向按缩放轴角向量
   写回(rapier3d 绑定实测:builder `.rotation()` 只接受 3 元组缩放轴角,不接受
   `Rotation3` 对象,`RigidBody` 无运行时 setter,删+建是唯一迁移路径——建议
   追加到 `demos/_API_NOTES.md`)。

## 风险与未覆盖

- 单块、平地、无堆叠:未验证凝固块旁/上再凝固(体素 set 并入、多体接触链)、
  斜坡慢爬行、大质量差、多线程 world 下桥的一致性。
- yaw 停在 27.4° 说明"睡眠位姿任意",snap 的视觉 pop(本例 383 mm)在
  Minecraft 视角下是可接受的方块吸附,但需要美术/交互层知情。
