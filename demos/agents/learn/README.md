## P1–P7 修复对照(R2 验收 → R3 落地)

- **P1(主因,奖励刷分)**:`align`(+max(0, v·u) 无上限)+ tier 阶梯 +
  保持窗口 ×3 + 线性+tanh 叠加全部撤除。R3 奖励 = 探针第三行基线
  `r = −dist − 0.01‖a_t−a_{t−1}‖² + 1[dist ≤ 3cm]`,`reward_scale 0.1`。
  **未在基线上加任何项**(align=0;要加须给加前/加后 L1 对照,本轮没有
  必要——s1 已达标,基线本身够用)。
- **P2(梯度步太少)**:`num-minibatches` 4→32、`update-epochs` 4→10
  (CleanRL 默认 32×10=320 步/迭代);`gamma` 0.995→0.99、`anneal-lr` 开、
  `target-kl` 不设,全部同 CleanRL。README 里"其余按 CleanRL 默认"的
  说法与 R2 实际值不符,已改正。
- **P3(ACT_SCALE 不一致)**:Rust 0.1、spec.py/README 0.05 → 统一 0.1
  (Rust 值为准,训练/评估实际一直走 0.1;"0.1 过冲重、0.05 稳"无依据,
  删除)。`learn_env` 模块导出全部环境常量(ACT_SCALE、KP、KD、TAU_LIMIT、
  JOINT_LIMIT、LINK_LEN、LINK_MASS、OBS_DIM 等 17 项),`check.py` 逐项
  与 spec.py 比对(f32 表示差按 float32 舍入后核对),不一致即 FAIL。
- **P4(出生角未生效)**:`reset` 改用关节坐标注入(`apply_displacements`
  + `forward_kinematics` + `update_rigid_bodies`,公开 API;R2 的
  `set_position` 对 multibody 连杆无效,第一步后弹回竖直)。新增单元
  测试 `reset_obs_is_self_consistent`:按观测 q 算正运动学,与观测末端
  相差 ≤ 1e-5 m(另有"出生角非恒 0"测试)。R2 的病征(obs q=0、末端
  已摆位、首步弹回)不复现。
- **P5(eval 口径)**:`policy_action` 不再自己钳——动作钳位进
  `Env::control_step`(训练/eval 同一入口);eval/order/det 全部复用
  `Env::reset_with_in` + `Env::control_step`(R2 在 main.rs 手抄的
  reset/步进 ~70 行删除)。
- **P6(GAE done 错位)**:后端到时步返回 **reset 前最后一次转移** 的
  reward_inputs(obs 照旧给 reset 后首帧),训练侧按 CleanRL 原样存
  `dones[step] = next_done`(obs[step] 是新回合首帧时 done=1),奖励
  不再置 0;`check.py` 加到时约定检查(trunc 步的 obs 是新出生帧、
  dist 有限非负)。
- **P7(L5 只应改 kp)**:`gain_mult` 只乘 KP,KD 不动(R2 连 kd ×0.7
  是超范围;力矩上限不动)。L5 的"kp 改成 ×0.7"按放行原文执行。

## 身体与参数(选定值;与 R2 相同)

- 根 fixed;link1/link2 各 0.5 m、1 kg(capsule_y,r=0.03);末端标记球
  r=0.02、0.01 kg 挂 link2;相邻连杆 `contacts_enabled(false)`;
  关节限位 ±170°;无地面;60 Hz、生产求解参数(只覆写 dt)。
- **PD 电机 kp 2000 / kd 60 / τ 25 N·m**。依据:最坏工况两杆水平时肩
  重力矩 ≈14.7 N·m;kp 2000 → 最坏静差 ≈0.0074 rad ≈ 末端 4 mm;
  kd:ζ = kd/(2√(kp·I_eff)),I_eff≈0.6,kd 60 → ζ≈0.87(L0 实证
  100/100;kd 20 时 ζ≈0.29 大行程 3 s 收敛不了)。τ 25 = 重力矩的 1.7 倍。
- 控制 2 拍(30 Hz),回合 90 控制步 = 3 s(60 Hz 对照 = 每拍设目标,
  回合同墙钟 3 s = 180 步)。
- 动作增量式:**目标角 += 0.1×a**(P3 统一后的事实值;R2 README 的
  "0.05 稳"说法删除)。
- 目标环形均匀采样 r∈[0.3,0.9](面积均匀),角全圆;出生角 ±0.5 rad
  (走关节坐标,P4);无提前终止。

## L1 评估(200 随机目标;确定性动作;最后 0.5 s 全部 ≤3 cm 判保持)

| 评估 | 保持 | d_end 中位数 |
| --- | --- | --- |
| s0 主口径 | 139/200 = 0.695(**未达标**) | 0.0135 m(达标) |
| s1 主口径 | **186/200 = 0.930(达标)** | 0.0068 m(达标) |
| s2 60 Hz 对照(--hz60 口径) | 103/200 = 0.515(只报数) | 0.0254 m |
| s1 L5 零样本(质量×1.5 kp×0.7) | 185/200 = 0.925 | 0.0069 m |

**L1 判据未达标**:放行要求"两个种子都满足",s0 = 139/200(0.695)
差 41 个。s0 失败行的 d_end 中位 0.0769 m、p25 0.043 m:多数回合末
停在目标附近但保持窗口里有一步出界(部分失败行 d_end < 3 cm),
即"到达但 15 步保持不严";未归因到单一机制(动作是积分器,到达后
需要连续输出 ≈0,σ 采样与控制粒度都可能贡献;没有做消融,不写死原因)。
s1 失败 14 行中位 0.1649 m(少数目标完全没到位)。

## 连杆顺序(R2 §9;只报数)

主体之前插入 1/4/16 个睡着刚体,s1 策略 200 目标:三档全部 186/200、
d_end 中位数逐位 0.0068——与干净世界(s1 = 186/200、0.0068)完全一致。
**结论:打乱顺序对摆臂任务无影响**(无地面接触,链路短)。任意排列
(blocks)布景未做:摆臂无地面、无可碰撞邻体,该布景在此任务上无差异
来源(如实注明,不编数)。

## 导出与文件

- `out/s{0,1,s2_hz60}_policy.onnx/.toml`、`out/s1_l5_ft_policy.onnx/.toml`:
  actor 均值网络(2×64 tanh,torch.onnx.export,opset 17,权重内联),
  policy.toml 含 body_hash=arm-demo、控制频率、观测布局、动作缩放(0.1)、
  归一化参数(§5.2;`learn eval` 读同名 toml 做归一化)。
- 复现:`learn eval out/s1_policy.onnx [--hz60] [--mass m --gain g]`。

## Rust 侧子命令(`learn <cmd>`)

- `l0 <种子> [n]` — L0 环境自检;
- `eval <onnx> [--hz60] [--mass m] [--gain g] [--out 名]` — L1 矩阵;
- `order <onnx> ...` — 连杆顺序打乱三档;
- `det <onnx> ...` — 双跑逐位;
- `throughput <n>...` — 纯物理吞吐矩阵;
- `torchtract <onnx> <obs.bin> <torch_out.bin>` — torch↔tract 最大差。
