## 卡在哪(未达标原因;如实)

策略学会了**朝目标方向甩臂并经过目标附近**(训练曲线 dist_mean 0.7;
60 Hz 口径 reach_frac 3.3%、s2 策略采样态 Python 口径 64 env 抽测
hold 15/64、≤10 cm 31/64),但**不会在 3 cm 内减速停住**:

- 动作是积分器(目标角 += 0.05a),到达后需连续给出 ~0 的动作;
  σ≈0.21(采样噪声)× √15 步 ≈ 4 cm 随机漂移,恰在门槛上;
- 1e7 步预算内,接近目标的状态占比极低(30 Hz 两种子 <0.2%,60 Hz
  3.3%),精修策略(把 σ 压小 + 微调目标角)得不到足够梯度;
- 高斯噪声采样的动作一半时间在饱和区外推目标角,"停在 0 附近"的
  行为从未被稳定执行过,return 信号被噪声淹没。

R2 放行:达不到判据时不放宽、如实报告后停——本 README 即停点。
若总架构师裁定继续,备选方向(未实施,供讨论):curriculum(先近目标)、
动作低通(状态反馈滤波)、或把"到达"从逐步奖励改成过程奖励模型。

## 微调路径(L4/L5;R2 补充)

- **L4 `--init-from` 接得上,达标**:从 s1 最终检查点(最后 20 迭代
  ep_rew 均值 −115.31)恢复,微调首迭代 −111.76,差 3.08% ≤ 20%;
  全程无 NaN(5 分钟,1e7 步)。检查点含 actor/critic/log σ/归一化
  统计/优化器状态/spec/超参;`spec_matches` 逐字段核对。
- **L5 模拟后端物理差异**(连杆质量 ×1.5、增益 ×0.7(ζ 不变),只改
  物理,spec 不变):零样本 1/200 → 微调 1e7 步(10 分钟内)→ 1/200,
  **未回到 ≥90%**。结论如实:微调在"策略本来就没学会"的基线上没有
  可迁移的余量——L5 的判据隐含 L1 达标,本单元 L1 未达标,L5 的
  "接得上物理"部分(权重/归一化在变异物理上正常训练、无 NaN、
  零样本与微调行为连续)已由数据证实。
- L4/L5 的 eval 前后对照见 `eval_s1*.csv`;微调曲线 `train_l4_ft.csv`、
  `train_l5_ft.csv`。

## 导出与文件

- `out/s{0,1,s2_hz60}_policy.onnx/.toml`、`out/s1_l5_ft_policy.onnx/.toml`:
  actor 均值网络(2×64 tanh,torch.onnx.export,opset 17,权重内联),

## Rust 侧子命令(`learn <cmd>`)

- `l0 <种子> [n]` — L0 环境自检;
- `eval <onnx> [--hz60] [--mass m] [--gain g] [--out 名]` — L1 矩阵;
- `order <onnx> ...` — 连杆顺序打乱三档;
- `det <onnx> ...` — 双跑逐位;
- `throughput <n>...` — 纯物理吞吐矩阵;
- `torchtract <onnx> <obs.bin> <torch_out.bin>` — torch↔tract 最大差。
