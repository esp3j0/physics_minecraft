## R2 改动(对应验收 DR1–DR3)

- **DR1 摩擦(替换 R1/CR1)**:撤掉 `CoefficientCombineRule::Min`,胶囊
  碰撞体用默认 Average 合成。R1 数据的副作用:胶囊对地面/方块都无摩擦,
  重物擦边砸中时倾斜接触力无摩擦阻挡,把胶囊横向挤出 89–98 m、速度峰值
  110–112 m/s(对照数字见"重物"小节)。改法:接缝钩子里对**胶囊对固定
  刚体的每一个流形**设 `*friction = 0`(`ModifiableManifold.friction`,
  per-manifold API,应用到流形内全部接触点),放在法线条件判断**之前**,
  墙面(斜法线)也包括;对动态刚体的流形不改。μ 的含义(本版起):只决定
  胶囊对动态方块的摩擦(按 Average 与对方 0.6 合成)。新增列
  `fric_zeroed`(每行被清零摩擦的流形次数)。
- **DR2 `dist` 符号**:R1 代码 `sc.dist = (vert_gap·sign).max(...)`,其中
  `sign` 取自法线 y 的符号——胶囊是 collider1 时法线朝下、sign = −1,
  竖直间隙被当成穿透。R1 未触发只因地形都在胶囊之前插入(胶囊恒为
  collider2)。本版改成 `sc.dist = vert_gap.max(sc.dist.min(0.0))`,不再乘
  法线符号(分离距离沿法线的投影就等于竖直间隙,与法线朝哪边无关)。
  新增对照行 `walk_T1_late_s4p3_h{0..7}`:先插胶囊再建 T1 地形,其余同
  `walk_T1_s4p3`——broad phase 按 collider 索引规范 pair 顺序,先插胶囊
  → 胶囊是 collider1。报 `edge_snaps` 和 vy 峰值(门槛 ≤0.5);代码断言
  这些行里胶囊至少有一次以 collider1 进入钩子(钩子内纯观测计数,不受
  edgefix 开关影响),次数写入 `cap_is_c1` 列。
- **DR3 文字**:推方块位移与 τ 的关系改写为"未归因"(三套候选的 F_max、
  air 同时不同,无单变量对照,因果说法没有依据)。
- **扫描**:μ 维度在平地和台阶上不起作用(摩擦在钩子里对固定刚体清零,
  μ 只进动态方块),扫描阶段固定 μ = 0.3,其余网格不变,候选选择规则
  照旧。选出候选后,对**推荐候选 c3** 另跑 μ ∈ {0, 0.3, 0.6} × 场景 6、
  6b、7、8(名字段 `_mu0` / `_mu0p3` / `_mu0p6`),按"重物位移最大值、
  速度峰值最小,并且无 panic、无 NaN"定 μ(结果与规则见"μ 三档"小节)。

## 身体与控制器(§2.2)

- **水平力** `F = clamp(m·(v_target − v_h)/τ, F_max)`,空中乘 `air`;
  30 Hz 决策、60 Hz 施加(rapier 0.36.1 的 `add_force` **不自动清零**,
  文档写明持续生效到 `reset_forces`——每拍先清旧力再施加);
  `|F| < 0.01 N` 不施加(允许入睡);
- **跳跃**只在接地时生效:先 `set_linvel` 清竖直速度,再加
  `m·sqrt(2 g h_jump)`;**只用力/冲量/速度清零,不直接设水平速度**;
- **接地判定**两种都实现(名字段 `mode=ray|shape`):射线从胶囊底部上提
  5 mm 向下(行程 `ground_eps`);球投射(R1/CR2)用半径 0.28 m 的球、
  球心从下半球球心上方 5 mm 下扫 `ground_eps + 0.025`;命中面法线
  y ≥ 0.7 才算接地。
  **rapier 0.36.1 实测坑**:`cast_shape` 的 `target_distance` 必须 > 0
  ——resting 时接触被推到 slop 内,`target_distance=0` 返回 None;
  本 demo 用 0.002 m(≪ ground_eps 档位,不改变判定含义)。
  本版 ground_frac:三候选全部场景 == 1.0000(summary
  `ground_frac [c*]` 六个小节 8/8)。
- **接缝修正钩子**(R1/CR3 + R2/DR1、DR2):见"R2 改动";`edge_snaps`
  是全程被摆正的流形次数,`fric_zeroed` 是全程被清零摩擦的流形次数,
  `cap_is_c1` 是胶囊以 collider1 进入钩子的次数(纯观测)。钩子的
  摩擦清零开关(`fric_zero_on`)独立于法线摆正开关(`enabled`):
  接缝 `_fix0` 对照行**保留**摩擦清零、只关法线摆正——对照行不做被测的
  操作,接缝对照的被测操作是接缝修正,不是摩擦。
