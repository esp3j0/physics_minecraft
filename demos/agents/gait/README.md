## 问题

一只 Go2 真实尺寸的四足(约 15 kg、12 自由度),用 rapier multibody + PD 电机,在
**全世界 60 Hz、不做子步、生产求解参数**的条件下,靠运行时更新关节目标,能不能
开环对角小跑走起来(≥ 0.1 m/s)、不发散。

## 步态(R1-3:足端轨迹 + 2 连杆逆解)

开环对角小跑(FL/RR 与 FR/RL 反相),无接触反馈:

- **足端轨迹**:支撑相(duty 0.5)足端匀速后扫 `x0+stride/2 → x0−stride/2`,
  摆动相 smoothstep 前摆 + 正弦抬脚 `lift·sin(πu)`;
- **2 连杆逆解**:足端 (dx, dy) 相对髋 → hip_pitch = φ−k/2、knee = k
  (φ = atan2(dx, −dy),k = 余弦定理折角);
- **起步序列**:直腿悬空(2L+足半径+2 mm)→ 1 s smoothstep 降到足端
  **0.28 m** 站高 → 2 s 站稳 → 步幅/抬脚 1 s 渐入,之后行走 3600 拍(60 s);
- 目标每 2 拍(30 Hz,D10)更新一次,每拍(60 Hz)做对照;
- 逆解的 hip_lateral 目标恒 0(平面步态,x–y 内摆)。

## 与首轮(064b359)结论的差异——错在哪

首轮"30 Hz 目标 + 23.7 N·m + 60 Hz 求解抬不起脚、前进判据达不成"的结论
**不成立**,根因在我们自己的模型和步态,验收评论五条问题全部证实:

1. **腿短一半**:旧模型腿长 0.11+0.12=0.23 m(Go2 真实 0.426 m),站高 0.33 m
   只能接近伸直,没有抬脚余量。换真实几何 + 足端逆解后脚离地 4.6 cm,
   前进 0.53 m/s;
2. **"折 0.15 rad 只抬 1.3 mm"是几何算错**(正确 ~5.7 mm),且旧 `feet` 列
   没算小腿倾斜(0.5 rad 倾斜误差 ~7 mm,比被下结论的 5 mm 还大);
   R1 测量改成 shank 刚体位姿算真实足端世界坐标(R1-6);
3. **−4.5 cm"穿透"是旧模型相邻连杆恒定重叠**;`contacts_enabled(false)`
   后最深 5.9 mm,且跪死不复现(R1-2);
4. **×0.01 的差异归因错**:不是"信噪比""冲击小两个量级",是 rapier 给
   multibody 设的**绝对常量阻尼 0.1** 不随质量缩放;阻尼同比 ×s 后两种
   质量比例在报告精度内一致(R1-5,上表);
5. 首轮 README"试过什么"有几行(knee_lift 0.5–0.7、脚垫 ball、深蹲 −0.9、
   关节接触开关)**没有对应数据**却写成"都留了数据"——本版删掉无数据行,
   旧模型与旧结论只在"历史"一节保留一句。

## 三个 rapier 坑(生产实现要避开)

1. **revolute 的电机/限位恒在 AngX 槽**:不管世界转轴是 x 还是 z,
   `RevoluteJoint::new(axis)` 都是把"主轴 = local X"转到给定世界轴,
   `LOCKED_REVOLUTE_AXES` 恒锁 AngY/AngZ;对 AngZ 槽写电机落在锁定位上,
   约束根本不建(探针证据:`num_velocity_constraints = 0`)。写电机一律用
   `JointAxis::AngX`;
2. **站立平衡后 island 会睡眠**:睡着后电机约束不再被求解,起步目标永远
   不生效;**目标变化时须对 multibody 全体刚体 `wake_up`**(生产的 D10 控制
   周期语义等价于"目标变化即唤醒");
3. **关节默认阻尼是绝对常量 0.1**(`Multibody::damping()`,根节点角自由度
   + 每个关节各 0.1),不随质量缩放;质量比例缩放时必须同步缩放阻尼,
   否则 ×0.01 档的阻尼比缩放后的 kd 还大(kd3→0.03、kd0.5→0.005),动力学
   完全不等价(D9)。
