## 问题

足端半径 2.2 cm 的小脚走过**贪心合并的体素碰撞体**时,共面的盒子接缝会不会
卡脚、抖动或被弹起?

## 运行方式

```bash
cd demos/agents/terrain
cargo run --release            # 全部 25 组(5 工况 × 5 航向,约 10 s)
cargo run --release -- det     # T2 双跑确定性比对
cargo run --release -- eight   # 8 只同世界耗时组(T2)
```

每次运行写 `out/run_summary.csv`(gitignore,不覆盖提交数据)。
**提交的原始数据**:`out/matrix_submitted.txt`(25 组全表)、
`out/det_eight_submitted.txt`(确定性 + 8 只耗时)。

## 地形与生产一致(放行硬要求)

- 路径依赖 `physics-sim`,直接调 `collider_build::greedy_colliders`,
  每 chunk 一个 fixed 复合碰撞体,friction 0.6 / restitution 0
  (同 `rebuild_chunk_collider`,sim.rs:4179-4208);没有手写另一套合并;
- 体素 = `Superflat::classic()`(bedrock×1 + dirt×3,世界 y −64..−61),
  **地面顶面 = 世界 y = −60**(生产布景纪律,同 sim.rs `drop_origin_y` 注释);
- 世界参数:60 Hz、`IntegrationParameters` 全 rapier 默认只覆写 dt、重力
  −9.81、无子步,与 gait/生产一致;
- 工况域:chunk x ∈ −2..14、z ∈ −2..2(16 m × 80 m);步态 = 默认组
  (kp100 kd3,f 3 Hz,步长 0.15,抬脚 0.06,脚摩擦 0.6,30 Hz 目标更新)。

## 判据相关说明(先读)

**全部 25 组都在 3600 拍内提前结束(`left_lane`)**——这是开环步态固有的
横向漂移,不是地形现象:`gait` 已记录(§13)kp100 kd3 f3 s0.15 在平地上
60 s 横漂 −3.33 m。行走带 = 出生点 + 初始航向轴线 ±4 m(放行没规定带宽;
这是本 demo 的实施口径),名义航向 ~1500 拍(25 s)、±1° ~1300–1900 拍、
±2°/T1/T2 的 −2° 组最长 3500+ 拍越带。放行预期如此:"离开行走带或掉坑就
提前结束,按实际拍数归一化"。比较口径 = 沿机身航向速度的**时间均值**,
提前结束不影响公平性(T0 与 T1/T2/T3 在同带宽下截断)。

T4 的 −2°/−1° 两组在走下台阶后 ~1420 拍摔倒(up·y → −1,身体贴地滑行)。
**开环航向敏感、摔后不恢复是 gait 已证明的现象**;T4 判据只有"无 NaN、
穿透 ≤ 5 cm、连杆速度 ≤ 跌落速度 2 倍",摔倒本身不在判据内,如实报。

### 观察到的现象

1. **没有卡脚、没有被弹飞**:全矩阵连杆速度上限 2.11 m/s(T1/T2 的 −2°
   长程组;名义航向组都 ~2.02,与 T0 相同),机身 |vy| 除 T2_h2 外全部
   ≤ 0.29 m/s,与 T0 同水平。沿航向速度 T1/T2 与 T0 差 < 1%,且 T1/T2 的
   长程组(−2°,3500+ 拍 ≈ 30 m)速度反而略高——接缝没有造成可测的减速;
2. **T2_h2 一次颠簸(up·y 0.989 → 0.9159,max vy 0.86 m/s)**:名义航向
   走过 T2 接缝带时发生一次明显弹跳,同地形 ±1°/±2° 五次里其余四次无此
   现象,同一组重跑逐位复现(哈希同)。发生拍 ~1400(机身 x ≈ 16 m 附近,
   跨 chunk cx=1 边界)。**嫌疑是某条接缝的合并盒边沿**,但没有逐拍接触点
   取证,不写根因;幅度 0.86 m/s ≤ 跌落判据的弹飞阈值,步态未失稳;
3. **法线倾斜计数高但与地形无关**:全组 ~8–15 次/千拍,T0(无接缝)也有
   8.8k/千拍量级——这是脚 ball(r=2.2 cm)与 cuboid 地面接触的正常流形
   倾斜(球-盒接触法线随接触点偏离球心竖直),不是卡棱。T3(45°)计到
   14–15k/千拍,与 T2 同地形 0° 的 12.2k 同量级。**按放行"如实报数、
   没有定值",待裁定**:如果要的是"卡棱次数",现口径混入了大量球面接触
   噪声,可改成"法线倾斜且该流形穿透 > 1 mm"之类更窄的口径,但那需要
   重跑,先报现象;
4. **T4 走下 1 m 台阶**:h2/h3/h4 三组顺利走下并继续走到越带,穿透与
   平地相同(4.3 mm),没有棱边弹飞;h0/h1 摔倒(见上),摔倒后的贴地
   滑行穿透 17–23 mm,仍 ≤ 5 cm。

### 8 只同世界耗时(T2 地形,沿 x 间隔 2.5 m,互不接触,1800 拍)

P50 **1.11** / P95 **1.16** / max **2.29** ms(单只 T2:P50 0.14 / P95 0.15)。

明显额外开销。
