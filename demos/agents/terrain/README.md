## 问题

足端半径 2.2 cm 的小脚走过**贪心合并的体素碰撞体**时,共面盒子接缝会不会
卡脚、抖动或被弹起?

  gait/mass 一致;步态 = 默认组(kp100 kd3,f 3 Hz,步长 0.15,抬脚 0.06,
  脚摩擦 0.6,30 Hz 目标更新)。

## R1 修正项

   其中接触点距接缝 ≤ 足半径的数量、min |n.y|。**口径自检:T0 倾斜数
   必须为 0——25 组实测 T0 全部为 0**(旧口径 T0 有 13358 次,全是自身

### 法线倾斜(窄口径)与口径自检

- **T0(大平面,无接缝)5 组倾斜全部为 0**,min |n.y| = 1.000——口径
  自检通过,证明旧版"球脚与盒面正常流形倾斜"的解释不成立(球-平面
  接触法线恒竖直),旧计数混的是自身连杆对;
- T1/T2 每组 23–59 次、T3 74–107 次(占脚-地形流形的 ~0.4%,全矩阵
  1002 / 218050);**其中距接缝 ≤ 足半径(2.2 cm)的:T1/T2 约 50%、
  T3 55%**——倾斜接触集中在接缝旁,是脚压上相邻合并盒边沿时法线倾斜,
  不是卡棱:T1/T2/T3 的速度、up·y、机身 vy 与 T0 无可测差异(判据 2
  全部 99.5%+),倾斜流形在下一拍内恢复正常法线(事件表无一次由倾斜
  引起的颠簸);
- min |n.y| 降到 0.00000 的组(T1/T2/T3 各航向都有):个别流形的法线
  接近水平(脚正压在合并盒竖直边沿上),同一拍内其余接触点法线正常,
  无绊阻后续步态。这是"脚跨接缝"的直接证据,如实报数,危害评估:
  25 组无一产生 > 0.35 m/s 的机身竖直速度(T4 摔倒组除外)。

## 观察到的现象(汇总)

1. **接缝不卡脚、不弹飞**:T1/T2/T3 对 T0 的速度比 99.5–101%,机身
   |vy| 与 T0 同量级(≤ 0.29 m/s),连杆速度上限 2.06 m/s(全部组,
   T4 摔倒段除外);跨缝 76 次(T2 名义组)无一产生可测扰动;
2. **倾斜法线集中在接缝旁、占比 0.4%、无后续效应**——"共面盒子接缝"
   在当前物理参数下的表现为:脚压过边沿时一拍内的法线倾斜,不产生
   卡阻或弹起;
3. 开环横漂限制长程(±2° 走 ~30 m 后离带),与 gait 结论一致;
4. T4:开环走下 1 m 台阶 = 5/5 摔(gait/探针一致),摔倒过程无 NaN、
   对地穿透 ≤ 22.9 mm、连杆速度 ≤ 7.4 m/s ≈ 1.7× 跌落末速(T4 判据
   的 2 倍上限以内)。
