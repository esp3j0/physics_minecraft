## 问题

足端半径 2.2 cm 的小脚走过**贪心合并的体素碰撞体**时,共面盒子接缝会不会
卡脚、抖动或被弹起?

## 观察到的现象(汇总)

1. **接缝不卡脚、不弹飞**(R1 结论,R2 口径修正后不变):T1/T2/T3 对
   T0 的速度比 99.0–101%(含全部 extra 档),机身 |vy| 与 T0 同量级
   (≤ 0.30 m/s),连杆速度上限 2.13 m/s(全部组,T4 摔倒段除外);
2. **倾斜法线 100% 在接缝旁、占比 ~0.08%、无后续效应**(空流形过滤后
   的窄口径数字)——"共面盒子接缝"在当前物理参数下的表现为:脚压过
   边沿时一拍内的法线倾斜,不产生卡阻或弹起;
3. 开环横漂限制长程(±2° 走 ~30 m 后离带),与 gait 结论一致;
4. T4:开环走下 1 m 台阶 = 5/5 摔(gait/探针一致),摔倒过程无 NaN、
   对地穿透 ≤ 22.9 mm、连杆速度 ≤ 7.4 m/s ≈ 1.7× 跌落末速(T4 判据
   的 2 倍上限以内);
5. `extra`(按主体追加求解迭代)在体素地形上同样安全,但 8 只 P95
   随 extra 线性上涨,extra 8 起超过 AC-B7 初定增量线——是否常开由
   B 阶段按数据决定。
