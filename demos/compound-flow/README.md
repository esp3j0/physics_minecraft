# compound-flow —— REQ-010 修订 12 单元 G00 demo:自由复合体的惯性汇点冲量流(§5.8)

需求:REQ-010 §5.8(D16 惯性汇点最大流、D17 断面动量分配、D18 可见变化、D19 默认开启;
2026-11-01 拍板)。本 demo 用纯函数 + rapier3d 实测回答任务书(G00-compound-flow-demo.md)
的 5 个问题。**G00-2 返修版**(2026-11-02,按 #22 裁定修正坐标系/冲量方向/侧撞几何后
全部重跑)。本目录不改需求文档与 crates/。

## 运行方式

```
.venv\Scripts\python.exe demos\compound-flow\flow.py       > flow_out.txt      (~2 分钟)
.venv\Scripts\python.exe demos\compound-flow\momentum.py   > momentum_out.txt  (~8 分钟)
```

环境:`rapier3d==0.36.0 + numpy`(已有 `.venv`,不装任何东西)。`common.py` 是
§5.8.1 纯函数(compound_flow / rigid_response / d4_rule)与 rapier 工具;
`flow_out.txt` / `momentum_out.txt` 是 2026-11-02 的实际运行输出(README 全部数字
出自它们)。

坐标与材料(同 F00):局部坐标、地表 y=0;地面 = y−4 bedrock、y−3…−1 dirt(薄片
内缩口径);stone I 18 / I_c 72、dirt 7 / 28;每格 cuboid 半边长 0.45、密度 1
(0.729 kg);dt=1/60;接近速度门槛 1 m/s(勘误 2:按流形,质心与逐点口径取大)。

**G00-2 修正口径**(裁定 #22):
- 事件统一在**刚体局部系**构造:`p_local = R_bᵀ(p_w − t_b)`、`J_local = R_bᵀ J_w`;
  格心用 collider 的 `translation_wrt_parent`(offsets);`add_compound` 断言
  collider↔格 按 `translation_wrt_parent` 匹配,不依赖创建顺序;
- 接触点含旋转:`p_w = t_c + R_c·local_p`(collider 的 position/rotation);法向用
  对方 collider 旋转转世界;高速投射物开 CCD(`ccd_enabled(True)`);
- J 一律指向 B 内部(地面 +y;侧撞从受击面指向格内),flow.py 断言
  `J·(质心 − p) > 0`;
- 单格自身惯量 = m(2h)²/6(立方体绕任一轴;G00-2 复核:写成 /12 会把 Δω 放大
  2 倍,rapier `apply_impulse_at_point` 对照核过);
- "横撞"= **侧撞**(垂直于条轴线打侧面);沿轴线的旧几何改名"轴向撞"单独对照;
- 速度换算统一约化质量:`u* = s*·(m + m_eff)/(m·m_eff)`,m_eff = p 处沿 d̂ 的
  整刚体有效质量(含转动),μ = m·m_eff/(m+m_eff)。
