# compound-flow —— REQ-010 修订 12 单元 G00 demo:自由复合体的惯性汇点冲量流(§5.8)

需求:REQ-010 §5.8(D16 惯性汇点最大流、D17 断面动量分配、D18 可见变化、D19 默认开启;
2026-11-01 拍板)。本 demo 用纯函数 + rapier3d 实测回答任务书(G00-compound-flow-demo.md)
的 5 个问题。结论由总架构师回写 §5.8 与 AC-G;本目录不改需求文档与 crates/。

## 运行方式

```
.venv\Scripts\python.exe demos\compound-flow\flow.py       > flow_out.txt      (~2 分钟)
.venv\Scripts\python.exe demos\compound-flow\momentum.py   > momentum_out.txt  (~6 分钟)
```

环境:`rapier3d==0.36.0 + numpy`(已有 `.venv`,不装任何东西)。`common.py` 是
§5.8.1 纯函数(compound_flow / rigid_response / d4_rule)与 rapier 工具;
`flow_out.txt` / `momentum_out.txt` 是 2026-11-02 的实际运行输出(README 全部数字出自它们)。

坐标与材料(同 F00):局部坐标、地表 y=0;地面 = y−4 bedrock、y−3…−1 dirt(薄片内缩口径);
stone I 18 / I_c 72、dirt 7 / 28;每格 cuboid 半边长 0.45、密度 1(0.729 kg);dt=1/60;
接近速度门槛 1 m/s(勘误 2:按流形,质心与逐点口径取大)。

## 2. momentum.py(rapier 实测)

### 2.1 刚体响应重建(任务书问题 1)

单格 20 m/s 横撞零重力静止 6 格石条端格,撞击拍 t=2:|J| = 12.725 N·s。
由读到的 J 与 p 重建的逐格 Δv_i 与 rapier 步进后速度场之差:**最大 8.13e−2 m/s,
为 s/M 量级(2.91 m/s)的 2.80%**——§5.8.1"Δv_i 即 rapier 本拍把 J 按刚体
分给各格的结果"成立(残差与 F00 直读 vs 动量差分 3.1% 同源:逐点分配的
超静定部分)。

### 2.2 rapier 单拍交付多少冲量(任务书问题 2 的前半)

零重力横撞(自由投射物 → 静止复合体)首拍实测:**s = |J| = μ·u,μ = mM/(m+M)
= 0.625**(u=180 时 s=112.483 vs μ·u=112.500;u=138 时 86.24 vs 86.25)——
rapier 单步交付的正是完全非弹性解析解,§5.8 的前提("rapier 已按整体刚体
解算")数值成立。但 u 大时(≥120)投射物单拍穿透 1–2 格,接触点落在被撞格
**和它的邻格**上,且两个接触面的逐点法向相反(投射物分别在两格的 +x/−x 侧),
冲量矢量和严重对消:u=173.5 时 **s=|J|=108.15 而 Σ|j|=539.66**(约 5 倍);
u=86.6 时 s=54.12 vs Σ|j|=116.22。p 也随之跨格偏移。

### 2.3 一次撞击分几拍(任务书问题 2)

| 平落 16 m 石 | 单拍 78.31(t=110) | 断 | 同左 |

| 端角 16 m 石 | 45.92(t109)、22.87(t118)、6.97、10.15、1.57、… | **两次"断"**(t109、t118) | 同左 |

结论:rapier 把一次落地撞击分 2–3 个大拍 + 若干小拍给出;第二拍(t89/t118)

"同一根粘结被反复判定"),无需合并窗口——见问题清单 P4。

### 2.5 平落为什么会断(本 demo 最重要的实测发现,问题清单 P2 核心证据)

16 m 平落石条首撞击拍(t=110)的诊断(momentum_out.txt 工况 2 打印):

- 冲量加权 p = (1.00, 0.075, 0.50),距质心 (3.0, 0.5, 0.5) 偏 2.0 m →
  Δω_z = −11.98 rad/s;
- 旋转使远端格(格 4、5)的 Δv_i·d̂ < 0 → **d_i = 0**(惯性汇缺失);
  Σd_i = 87.15 仍 > s = 78.31,但格 4/5 的汇没了之后,供给必须穿过
  格 3→格 4 的粘结边(I=18)才能流向右半,**C = 65.84 < s = 78.31 → 断,
  S = 格 3、4、5**;
- (探针逐格冲量,未入存档:78.31 中约 49 在格 3、23 在格 1,其余 4 格
  合计 6 —— 供给极不均匀,这是 p 偏心的直接原因)。

§5.8.1"平落不断"的论证假设供给均匀(每格自己的汇就近吸收);rapier 的逐点
解算把冲击集中到先接触的一两格,均匀性不成立。这是 §5.8.5 标量流近似
(只按 d̂ 分压向/剪拉、不算弯矩)与"p = 冲量加权质心"两条约定共同作用的
结果,**不是实现 bug**(case4 校验 ①② 与守恒残差全部 0.00%,见 2.7)。
§5.8.5 说该近似"旋转剧烈时偏结实",实测方向相反(偏碎)。若要保住
"平落永不碎"的设计意图,需要总架构师在 p 口径(冲量加权 vs 质心)或 d_i
的旋转项上做裁定——本 demo 不改规则。

**量化边缘提示**:平落阈值恰在判定边缘(C 与 s 差 < 1 个量化单位 0.001 N·s),
复跑 3.89/4.0 m 出现过"不断"的结果(判定对接触点求解器噪声敏感);远离边缘
处稳定(5 m 稳断:t=62, s=46.2, C=41.6;6 m C 与 s 差 0.65)。写 AC-G 数值时
建议避开边缘、取 5 m 以上或按 P2 裁定后的新口径重测。

### 2.6 横撞端格阈值 173.5 的构成(问题清单 P1/P7 的实测证据)

端格阈值处的首拍事件(u=173.5):投射物穿透,接触点跨格 1、2,逐点冲量
215.8 + 323.9,法向相反 → s=|J|=108.15(Σ|j|=539.66);事件构型恰是
flow.py"横撞第 2 格"(p 在格 1/2 之间、供给给格 1、2)→ 阈值 ≈
s*(第 2 格)108.002 / μ=0.625 = 172.8 ≈ 173.5 ✓。S = 格 1–5(端格留在 R),
即 **§5.8 判定断下的是"主体 5 格"而不是"撞点端格"**——穿透改变了事件构型,
这是事件构造(P7 口径)在高速下的行为,不是 bug。低速时接触点单格,
构型与 flow.py 工况 4 一致。

### 2.7 守恒与两条解析校验(任务书问题 3,§5.8.2)

校验工况:单格 0.729 kg、180 m/s 横撞 6 格石条端格(零重力),rapier 实际交出
s = |J| = 112.474 N·s;T=0 合成工况(S–R 粘结容量置 0 重求,C=37.492,E=74.982)。

1. **① 撞整条解析**:s vs m·M_R/(m+M_R)·u = 112.474 vs 112.474,**偏差 0.00%**;
2. **② 只撞 S 的解析**:T=0 合成下,撞击者交出净冲量 s − corr = 87.480 vs
   m·M_S/(m+M_S)·u = 87.480,**偏差 0.00%**(S = 2 格,M_S = 1.458 kg)——
   §5.8.2"结果与撞击者只撞上 S 的解析解逐式相等"成立;
3. **守恒残差** |ΣR 退还 + Σ对方修正 + ΣS 获得| = **0.00e+00**(校验 A)。

接地落体(对方 = 地形):平落 4 m 石条首撞击拍 t=55、s=39.3 → C=39.3,s=C
判定不断(恰在 2.5 的量化边缘下方);§5.8.2"S 恰好被止住、R 只减少 T"的
解析形态在 §5.7 串联工况(punch)里体现(见 2.8)。

### 2.8 与 §5.7 串联(任务书问题 4)

| 场景几何 | 现行 D4(修订 11 冒烟) | §5.8(rapier 实测) |
| --- | --- | --- |
| punch:6 格石条 20 m/s 撞土墙 | 石条断成 2+4 | **石条不断**(t=2 首事件 s=91.26=C;墙侧事件按 §5.7 先处理) |
| pillar:4 格石柱被 20 m/s 侧撞 | 整根从柱脚断 | **柱不断**(t=11,s=17.50=C) |
| corner:7 字被 40 m/s 斜撞拐角 | 整个 7 字从柱脚断飞 | **7 字不断**(t=11,s=31.11=C) |

**这是 D18"摔碎基本消失"的另一面:复合体侧的断开也大幅变难**。punch 里石条
不断意味着"前段穿洞、后段停墙前"的期望不再成立(石条整根被弹回或推过);
pillar/corner 不断意味着这两个场景在 compound_flow 开启后**没有断下事件**,
冒烟期望需要按"投射物单独弹回、结构保持站立"改写。注意:单拍口径的 s 很接近
C(差距 ≤ 量化误差),说明这些几何在 §5.8 下"差一点才断"——阈值敏感性高,
G03 定场景期望时需要总架构师按 §5.8.1 表的回写值重估。

### 2.10 计算代价(任务书问题 7)

216 格(compound_split_size=6 上限)单事件:建网 + EK + Dinic **20.32 ms**
(5 次中位;单次 22.68 ms)。Rust 按 1/50~1/100 折算 = 0.20~0.41 ms——
**在 0.2 ms 预算边缘**。分解:网络 ~2000 边,EK 以 BFS 增广为主;若 G01
只用一种算法(需求已证算法无关)可省一半;真正的热点是 Python 的逐边
容量计算,Rust 直接内联后大概率 < 0.2 ms,但需要 G01 用 Rust 实测确认。

## 5. 需求问题清单(§5.8 不成立 / 有歧义处,附根因)

- **P1|作用点口径不一致(估算表 vs 正文)**:§5.8.1 表"横撞端格石 ≈76 m/s"
  按"断下端格只需带动 5 格"(逐格局部 m_eff ≈ 1.14 kg、作用点端格外下角)
  估算;正文规定 p = 冲量加权质心、事件 = 整个复合体的全部计入流形——接触点
  在端格中心时整条 m_eff = 4.374 kg,阈值差 3.8 倍。实测还叠加了穿透跨格
  (2.6):低速单格接触时阈值 = s*(端格)/μ = 138.3 m/s,与估算 76 仍差 1.8 倍。
